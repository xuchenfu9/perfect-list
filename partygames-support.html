🎮 派对游戏技术支持

版本适用范围：本页适用于派对游戏 1.3.0。商店旧版 1.2.0 的对应说明请查看1.2.0 专用页面。

最后更新日期：2026-10-18

Party Games（派对游戏）包含点球大战、反应对决、幸运转盘、扑克翻牌、摸高挑战、手指炸弹和刹车挑战。应用版本请在设置或 App Store 中查看。

系统和连接要求

  • 设备：iPhone、iPad；需要 iOS / iPadOS 17.0 或更高版本。
  • 单机和同机派对无需 Game Center；已有附近模式使用对应的 Wi-Fi、蓝牙及本地网络权限。
  • Game Center 登录、排行榜、成就同步和版本检查需要可用的互联网连接。没有网络或 Game Center 不可用时，本地游玩仍可继续。

Game Center 登录

为什么启动时出现 Apple 登录界面？

正常冷启动时，应用会在大厅尝试一次系统登录。您可以取消并直接进入大厅；比赛中或应用处于后台时不会弹出登录。七款原有游戏首页均有 Game Center 按钮，可以稍后连接。

如何关闭自动连接或退出？

在应用设置中关闭“启动时自动连接”，可停止下次启动的自动登录尝试。这个开关不会退出已连接账号，已连接账号仍会同步合格成绩与成就。要停止该账号后续提交，请在系统设置中退出 Game Center。系统菜单位置可能随系统版本变化。

登录失败怎么办？

检查系统 Game Center 账户是否可用、互联网连接和系统家长控制限制，然后回到游戏首页手动重试。您不需要向技术支持提供 Apple 密码或验证码。

排行榜和成就

  • 反应对决：个人模式的有效反应成绩，越短越好。
  • 摸高挑战：个人标准模式、1.0 速度下的有效成绩，越高越好；自定义速度不计个人标准榜。
  • 刹车挑战：单人模式分别记录沥青、混凝土、雨天、砂石和雪地五个路面，时间越短越好。
  • 个人玩法共14张榜，完整在线足球另有净胜球历史榜和周榜，共16张。周榜按UTC周一00:00开始、持续7天，显示时会换算为本地时间。
  • 32项成就涵盖本人标准成绩、玩法体验及正常在线完成；自定义规则和同机他人成绩不会冒充个人标准成绩。在线扑克的安全翻牌仅计本人实际操作。

排行榜与成就还依赖 App Store Connect 目录配置、图片和 Apple 审核。完成本地接入并不代表线上目录已经生效；若显示不可用或无资料，请稍后重试或联系支持。

为什么显示“待同步”？

无网络、Apple 服务异常或榜单/成就目录尚未配置时可能同步失败。应用按当前玩家保存本机队列；可从原游戏首页 Game Center 菜单或设置中的“重试同步”再试。只有当前已连接账号的数据会提交，退出系统账号后不再提交。反应、摸高和五路面的挑战关联周榜仅提交当场联网的新有效成绩，包括非个人最佳；离线和历史周成绩保留本机，不在以后补投，也不对结果未知的新周榜报分自动重试。历史总榜、成就以及仍在有效周期内的足球周榜可继续重试。过期成绩不会补到下一周，提交前不保证线上已更新。

游客纪录能导入吗？

游客个人纪录留在本机，不会自动归入登录账号。连接后可在首页 Game Center 菜单选择导入并明确确认；仅导入属于您本人的单人历史最佳，不导入周榜、游客成就或同机朋友成绩。切换账号不会把另一账号的队列提交给新账号。

删除应用会删除线上纪录吗？

删除应用会移除本机应用数据，可能丢失尚未同步的纪录；系统备份行为由系统设置控制。已提交的 Apple Game Center 成绩与成就不会因此自动删除，请在 Apple 的隐私和账户渠道管理相关资料。

在线多人、活动与好友挑战

足球支持2人，摸高、刹车、翻牌和好友转盘支持2至4人。进入原游戏首页切换到在线区，可邀请好友；适用玩法还可自动匹配。普通转盘通过邀请好友组局；使用完整活动码加入同一活动后，可进入系统快速匹配。每台设备使用各自的Game Center账号，房间人数、路面、规则及参与名单需一致。反应对决暂不提供实时跨网对战；手指炸弹继续同屏游玩。

所有人准备后由房主开始。足球双方隐藏方向选择后揭示；摸高每人三次取最佳；刹车使用同一路面并核验各自输入；翻牌轮流操作；转盘共同生成并验证抽选结果。中断或缺少最终确认不会算作正常在线完赛。刹车断线后本人仍可完成本地停车，合格个人纪录可保留。再玩会重新发起系统邀请。

iOS/iPadOS 26可从原首页活动菜单创建活动、分享系统链接或输入派对代码。创建成功后，完整活动码会自动复制到系统剪贴板，也可点击活动码旁的复制按钮再次复制。“活动码已复制”和“本机活动已结束”提示会在3秒后收起。收到邀请时正在进行的局会被保留，可空闲后明确处理；代码和链接请只分享给预期参与者。旧系统保留普通邀请，不显示不可用的新派对代码入口。

反应、摸高及五种刹车路面共有7项系统好友成绩挑战，按所选周榜比较。挑战期限是当前周周期剩余时间，次数由Apple系统管理；普通有效新局也可能计入参加中的挑战。应用不显示未经系统提供的剩余次数，也不保证强杀或提前退出一定消耗次数。每次完整有效的新成绩都会提交，未破个人纪录也一样。

个人纪录跨设备同步

在原设置页开启独立的“个人纪录跨设备同步”；默认关闭，需要Game Center和系统iCloud Drive均可用。Game Center登录成功不代表iCloud一定可用。

开启后可合并同一玩家的标准最佳、成就事实和最近100场本人摘要。语言和上次标准路面等有限偏好可同步，自动连接与云同步开关不会跨设备传播。同一iCloud内切换Game Center账号仍按玩家隔离；多人对战测试用不同Game Center账号，个人云同步测试则应使用同一个玩家。

关闭开关会停止后续同步，保留本机及已有云端数据，不等于删除云存档。iCloud不可用、存档格式较新或容量达到安全上限时继续使用本机纪录，并显示状态。若出现冲突，应用加载并校验所有相关版本后合并，不直接相加两份累计次数；较旧历史可能保守少计。请勿向支持人员发送存档文件或账号标识。

附近连接和权限

无法找到附近玩家时，请检查设备是否进入同一游戏模式、是否连接同一 Wi-Fi，以及应用的蓝牙和本地网络权限。保持设备距离适中、信号稳定，并尝试重新进入模式或重启应用。

在系统设置中找到 Party Games，可管理相关权限。蓝牙和本地网络用于发现及连接附近设备；运动传感器用于体感交互，反应对决使用屏幕按钮。请只连接信任的玩家。

玩法速览

  • 点球大战：守门员秘密选方向，吹哨后射手选择方向；方向一致则扑出，否则进球。
  • 反应对决：看到“开火”后点击屏幕按钮，提前点击出局。
  • 幸运转盘：转动转盘进行随机选择或抽奖。
  • 扑克翻牌：轮流翻牌，避开隐藏的炸弹牌。
  • 摸高挑战：按游戏提示完成反应操作，比较虚拟摸高成绩。
  • 手指炸弹：多人同时按住屏幕，等待本轮随机选出参与者。
  • 刹车挑战：按游戏提示操作，比较不同路面下的刹车成绩。

闪退、卡顿或更新

完全关闭应用后重新打开，检查设备存储空间，并在 App Store 检查更新；必要时重启设备。附近模式出现延迟时，同时检查连接质量。如问题持续，请记录出现步骤并联系支持。

隐私

本应用不增加广告、分析或跨应用追踪。连接 Game Center 后，本人的合格成绩和成就进度会交给 Apple；本机保存按账号隔离的纪录和队列；在线操作会与同局设备交换，个人云同步仅在独立开关开启后进行。头像只用于会话展示，不持久保存或传给自有服务器。版本检查也会联网。详情见隐私政策及 Apple Game Center 与隐私。
